Embedding models

A separate list, because an embedding model has no output price, no cache and cannot think. Anthropic is not an option — it has no embeddings endpoint. Point this at a local server and the index costs nothing and no library data leaves the house.

The index

Built by the Build the Concierge search index scheduled task. Items that have not changed since the last build cost nothing, so a nightly run of an unchanged library is free. The index is a cache: deleting it degrades search and touches nothing in your library.

Quote search

Search for a line somebody says and get the film and the minute. Reads the subtitles already inside your files — no model, no embeddings, no money, only CPU the first time it reads each file. It is also the only part of Concierge that works on films no model has heard of, because the words come from the file rather than a model's memory. Run it from Scheduled Tasks → Read dialogue for Concierge quote search.

Off by default, and the reason is size rather than taste. Films are roughly 73,000 searchable windows and finish in minutes; the whole library is 850,000 and is an overnight job. Turning this on is also the point at which a proper full-text database would beat the index built in here — ask before relying on it at that scale.
Jellyfin already holds lyrics as time-stamped lines, so this needs no extraction and no ffmpeg — it is a read. Lyrics land in the same index as dialogue, because a remembered line is a remembered line and you should not have to know whether it was spoken or sung. A matched lyric deep-links to the second it is sung.
Forced tracks are never used — they carry only a few dozen foreign-language lines, so indexing one looks like success and produces a film nobody can find by anything said in it.
