Embedding models

A separate list, because an embedding model has no output price, no cache and cannot think. Anthropic is not an option — it has no embeddings endpoint. Point this at a local server and the index costs nothing and no library data leaves the house.

0 uses the model's native width. Set it only to truncate deliberately, which trades a little quality for a much smaller index. Changing it invalidates every stored vector.
bge-m3, E5 and nomic-embed-text are trained with markers telling a query apart from a passage. Using the wrong one degrades results with no error and no symptom, so these are filled in for models known to want them. Google and Voyage carry the distinction natively and need none. Changing either invalidates the index.

Which model runs which pass

The two per-query passes run forever and should be as cheap as quality allows. Enrichment runs once per item and sets the ceiling on what a half-remembered sentence can ever match — it should be the best model you can afford. Leave a pass on “use the default profile” to follow the default.

The index

Built by the Build the Concierge search index scheduled task. Items that have not changed since the last build cost nothing, so a nightly run of an unchanged library is free. The index is a cache: deleting it degrades search and touches nothing in your library.
This is what makes plot and mood searches work. Overviews describe the premise; people remember moments. John Wick's overview never mentions the dog.
